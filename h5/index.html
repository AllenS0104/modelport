接入 WorkBuddy / OpenClaw / VS Code

选择客户端支持的自定义模型提供商。若支持 OpenAI 兼容协议，通常需要以下三项；部分客户端会自行添加 /v1，请按其说明避免重复。

Base URL：待确认本站地址

API Key：在 API Keys 获取的客户 Key。

Model：在 仪表盘 核对的精确模型 ID。

VS Code 本身不是统一的模型客户端：请使用支持自定义提供商的扩展。GitHub Copilot 等产品不一定允许替换 Base URL。本站不承诺与所有插件、所有模型协议兼容。

远程客户端无法连接你电脑上的 127.0.0.1。跨设备使用需要管理员提供实际可达且受保护的 HTTPS 地址；不要将当前回环入口直接暴露公网。

常见问题

为什么没有网页聊天？

本阶段只提供 API Key 服务。请在自己的客户端使用模型；旧聊天链接会转向控制台，网页聊天请求已停用。

其他用户能看到我的 Key 或消费吗？

客户 Key 和消费记录按账户鉴权。请自行保管密钥，不共享主账户。管理员审计不在普通用户导航中提供。

邮件通知在哪里设置？

进入个人资料中的设置，保存通知邮箱和余额提醒阈值。邮件服务配置完成后可发送测试邮件；平台未配置 SMTP 时会明确提示，不会把保存设置当作发信成功。

平台是否提供 GPU 或自动部署模型？

不提供 GPU 租赁，不在客户侧部署模型。平台通过获准的上游 API 提供服务，实际授权、计费和限额由服务端执行。
